# Нейрозапуск

Отдельный лендинг программы для экспертов: продукт, AI-команда и подготовка системного запуска.

Сайт статический: `index.html` и изображения в `assets/`. Сборка и сервер не требуются. Для локального просмотра открой `index.html` в браузере или запусти статический сервер в этой папке.

Мини-группа длится две недели, индивидуальное сопровождение — четыре. Актуальные условия участия указаны на странице.

Сайт не собирает заявки и не принимает оплату: кнопки ведут к личным контактам ведущих в Telegram.
